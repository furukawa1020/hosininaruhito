# 恒星の方向計算と投影

POST /api/projectは、出典付きカタログの各恒星を、明示された地点・UTC時刻における方向へ変換し、身体配置用の形の下書きを返す。星をみるひとAPIの観測日時を推測する処理ではない。画面からの星座選択・振付との接続は後続の#15で行う。

## 入出力

入力は{id,lat,lng,at}のみ。idは星APIの1〜88、lat/lngは度単位、北緯/東経を正とする。atはYYYY-MM-DDTHH:mm:ss.sssZ形式で2000年〜2100年、UTCを明記する。存在しない日付・タイムゾーン省略・別形式・範囲外を拒否する。

出力のat/timeBasisはカタログ計算用の時刻で、星APIのprovider-default時刻とは一致を保証しない。計算だけでは観測API成功を意味しない。位置を応答本文やログへ複製しない。

## 座標変換と出典

[ Astronomy Engineの公式リファレンス](https://github.com/cosinekitty/astronomy/tree/master/source/js)とインストール済みastronomy.d.tsを確認し、MITライセンスの2.1.19をpackage.json/lockfileで固定した。ライセンス全文をthird-partyへ同梱する。

providers内でRotation_EQJ_HORを使い、J2000赤道座標を観測地点の水平座標へ変換する。赤経は度から単位ベクトルへ変換し、時単位と混同しない。SDKの水平ベクトルは北・西・天頂の順。HorizonFromVectorにより北0度、東90度の時計回り方位角と高度を得る。SDKはcoreへ持ち込まない。

標高は0m、大気差なし。歳差・章動はSDKの座標変換に含まれるが、恒星の固有運動・年周視差・大気の状態は補正しない。精密な天文計測やcm単位の実空間位置合わせを意図しない。

## 純粋な投影処理

coreはSDK・DOM・ネットワークに依存せず、検証済みの方位角/高度から形を計算する。

- 高度0度以下はbelow_horizonとして除外。対象0件は失敗。
- 可視恒星の単位ベクトル平均を投影中心にする。ゼロに近い中心や天頂の不定な回転は明示エラー。
- 接平面への心射投影を使い、中心から80度以上離れた星はoutside_projectionとして除外。特異点へ近づく無限大を許さない。
- 星が2個未満、同一点への縮退、未知の線分端点、不正値は失敗。
- 方位角増加方向が右、高度増加方向が上。xは右向き、yは下向き。ミラー反転しない。
- 縦横に同一の倍率と平行移動を使い、長い辺を[0.1,0.9]へ収める。倍率・中心・余白を応答に保持する。
- 除外した星の前後をつなぎ直さず、元の隣接端点が両方残る線だけ返す。除外理由も残す。

出力のnormalized-image-templateは画像正規化の形の下書きであり、カメラの向き・AR重畳・距離・世界座標を表さない。身体への配置は#11の実測点に基づく調整で別に検証する。12点を超える星座の振付での扱いも後続の統合課題。

## 検証

方位0/360跨ぎ、地平線、天頂、重複方向、星の欠落、線分維持、倍率、角度・日付の不正値を検証する。北極・南極・赤道・UTC日付境界では、別のSDK経路（J2000→当日の赤道座標→Horizon）との一致を確認する。同じライブラリ内の別経路照合であり、実測値や別の天文台データによる独立精度検証ではない。

実カタログで正常な投影を確認し、この処理で外部HTTP呼出がないことも試験する。星APIライブ応答との同時刻整合、現地の空との照合、画面・身体誘導との統合、実機とデプロイは未確認。
