drowingは不透明な文字列として保持し、恒星座標や線分に変換しない。画像URLも表示・再配布しない。
空配列は正常な0件として扱う。形式不正・重複ID・範囲外角度・過大応答は502。

## 2026-09-21 公式Markdownとカタログの追加確認

[星座一覧の公式Markdown](https://hoshimiru.apidog.io/星座一覧を取得-32979472e0.md)を取得し、OpenAPI YAMLを確認した。
dateはstringで例2020-01-15、hourはstringで例20、minはstringで例00。3項目ともrequiredとされている。
受理する全書式・境界値、タイムゾーン、日時省略時の動作は記載から確定できない。
従来実装のlat/lngのみ送信は実API未検証のままであり、省略が正常に動くことを保証しない。#4で確認する。
JST/UTCを推測して日時の送信を追加していない。

[公式認証資料](https://hoshimiru.apidog.io/認証-2072565m0.md)ではBearer Tokenの取得先をhttps://livlog.xyz/sso/loginと案内している。
利用者の依頼により取得を試みたが、ブラウザー連携がタイムアウトし、再初期化でもWindows helperのapply deny-read ACLsで起動に失敗。
ログイン画面・トークンには到達していない。認証を迂回する操作は行っていない。

恒星データの一次資料・ライセンス・ID対応は[CATALOG.md](CATALOG.md)に記録。
全88星座の原資料往復照合は静的な実データの試験であり、星APIライブ応答の確認とは区別する。

coreの非ミラー座標、描画だけの反転、実測値/時刻の保持、未確定点を飛び越す線の禁止をレビュー。

UI契約試験は合成座標・合成bitmap・制御した時計で実行。実時計ではGPU負荷による150ms停止も観測したため、
停止閾値は維持し、UI操作と実デバイス性能の検証を分離した。
