# Jevの低頻度助言

Jevは表示用の補助コメントだけを返す。毎フレームの目標、保持、capture、停止はHumanRuntimeが計測値で決める。
AIのconfidenceは応答形式として検証するだけで、到達・安全・capture・採用の確率閾値には使わない。

## 外部送信

撮影・位置・Codex計画とは別の「目標との差をTypeSafe AIへ送り…」への同意が必要。
同意後、実行中の目標と現在点の差dx/dyを小数第2位へ丸め、tracked=trueとともに認証付きPOST /api/reflexへ送る。
サーバーもこの3項目以外を拒否し、TypeSafeへ同じ3項目だけを渡す。
映像、地点、実測手首座標そのもの、星ID、時刻、軌跡は送らない。差は身体計測から導いた値であることを画面で明示する。

公式仕様: https://docs.typesafe.ai/introduction/quickstart
POST https://api.typesafe.ai/v1/systemone、Bearer TYPESAFE_API_KEY、既定モデルjev-latest。

## 制限と破棄

- 送信間隔500ms以上、同時1件。abortを無視する通信でもsettleするまで所有権を解放しない
- 1回の実行で最大60件。同意を外して入れ直しても同じ実行の回数はリセットしない
- 1秒で通信を中断。表示も送信時刻から1秒まで
- 150ms以内の新しい計測がない場合は停止。時計逆行・未来時刻・不正値を拒否
- 停止、同意撤回、実行世代、目標の変更後の応答は破棄
- APIエラー後は2秒待ち、連続3回失敗で助言のみ停止
- 応答の出典・助言専用フラグ・候補・confidenceの型を再検証
- 現在の幾何方向と一致しない助言は表示しない。現在点/目標が変われば表示を取り消す

上記はこの画面の助言処理の上限であり、サーバー全体の課金上限ではない。
開発用の固定入力接続試験は自動助言とは別の手動操作。公開には#17の認証/ユーザー別quotaが必要。
画面は鏡像なので、非ミラー画像座標のrightは「表示の左側」、leftは「表示の右側」と表示する。
輪と保持表示が常に主で、Jev障害が幾何判定や完成判定を置き換えない。

## 検証

仮想時計の単体14件で送信間隔・同時所有・キャンセル無視・ターゲット変更・鮮度・逆行・429相当・不正応答・60件上限を確認。
fixtureブラウザー5件で別同意・丸めた差のみ送信・遅い応答の破棄・高confidenceの誤助言拒否・障害後もローカル実行が続くことを確認する。
これらはライブAPIや実人体の成功証拠ではない。

`npm run smoke:jev` は固定の合成入力を1回だけ実APIへ送る。通常のcheck/CIには含めない。
TYPESAFE_API_KEYが未設定のため実API成功・実測遅延/失敗率は未確認。
応答時間の画面表示は各通信の単調時計による経過時間で、モデル推論時間そのものではない。
